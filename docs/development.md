# Clavis: устройство и сборка

## Как устроена защита

| Что | Как |
| --- | --- |
| Данные на диске | XChaCha20-Poly1305, отдельный ключ данных (DEK) |
| PIN-код | Argon2id (64 МиБ, 3 прохода) + секрет устройства, защищённый TPM и DPAPI + секрет из отдельного ключа TPM, который открывается только с PIN |
| Перебор PIN | неверные попытки считает чип TPM и после серии ошибок временно блокирует ключ; откат файлов этот счётчик не сбрасывает. Кроме того, после 10 ошибок PIN отключается, и открыть Clavis можно только фразой восстановления |
| Фраза восстановления | 24 слова BIP-39, 256 бит энтропии |
| Записи при заблокированном хранилище | шифруются открытым ключом X25519, читаются только после разблокировки |
| Код доступа | 24 символа из алфавита в 32 знака (120 бит), на сервере хранится только SHA-256 |
| Запросы к серверу | подписаны ключом Ed25519 устройства, защищены от повтора меткой времени и одноразовым nonce |
| Лицензия | подписана ключом сервера, проверяется в приложении, привязана к ключу устройства и отпечатку железа |
| Общие заметки | правки, курсоры и изображения шифруются ключом документа (XChaCha20-Poly1305) до отправки; ключ для каждого участника зашифрован его ключом X25519 |
| Удаление участника | ключ документа меняется (новая эпоха), удалённый не может читать новые правки |
| Каналы Realtime | имя канала выводится из ключа документа и меняется вместе с эпохой, поэтому посторонний не может найти канал по номеру документа |
| Ссылка-приглашение | одноразовая, 3 дня; сервер хранит хэш секрета, а ключ документа зашифрован ключом, выведенным из секрета, поэтому сервер не может открыть заметку |
| Менеджеры паролей | содержимое с пометками `ExcludeClipboardContentFromMonitorProcessing` и `CanIncludeInClipboardHistory = 0` не сохраняется |

Стойкость защиты не зависит от того, что исходный код открыт: без PIN-кода, чипа TPM этого компьютера или фразы восстановления данные не прочитать.

## Сборка

Нужны Node.js 22+, Rust 1.80+ и [зависимости Tauri для Windows](https://tauri.app/start/prerequisites/).

```powershell
npm install
npm run tauri build
```

Установщик появится в `src-tauri/target/release/bundle/nsis/`.

Интерфейс без ядра можно посмотреть в браузере на тестовых данных:

```powershell
npm run dev
```

Параметры адреса для просмотра разных экранов: `#view=picker`, `#view=main&section=notes`, `?stage=activate`, `?stage=locked`, `?owner=1`.

## Выпуск обновления

Сборка с ключом подписи создаёт рядом с установщиком файл `.sig`:

```powershell
$env:TAURI_SIGNING_PRIVATE_KEY = Get-Content clavis-updater.key -Raw
$env:TAURI_SIGNING_PRIVATE_KEY_PASSWORD = "пароль ключа"
npm run tauri build
```

Установщик и `latest.json` с подписью из `.sig` прикрепляются к новому выпуску на GitHub (Releases). Clavis ищет обновление по адресу `releases/latest/download/latest.json`, запасной адрес — хранилище `releases` проекта Supabase. Адреса и открытый ключ заданы в `src-tauri/tauri.conf.json`. Закрытый ключ в репозиторий не кладётся.

## Сервер

Сервер активации работает на Supabase: таблицы в `server/migrations`, функция в `server/functions/clavis`. Функция развёртывается без проверки JWT, потому что каждый запрос подписан ключом устройства. Адрес функции и открытый ключ сервера заданы в `src-tauri/src/license.rs`.

Первый код владельца создаётся вручную: сгенерируйте 24 символа из алфавита `ABCDEFGHJKLMNPQRSTUVWXYZ23456789` и добавьте SHA-256 от них в таблицу `codes` с `is_owner = true`. Компьютер, который активирует этот код, становится владельцем и получает панель управления кодами.

## Структура

```
src/                 интерфейс (Svelte 5)
  views/             окна и разделы
  lib/               поиск, преобразования, переменные, экспорт в Word
src-tauri/src/       ядро (Rust)
  crypto.rs          шифрование и вывод ключей
  vault.rs           зашифрованное хранилище
  device.rs          TPM, DPAPI, отпечаток железа
  license.rs         активация и связь с сервером
  shared.rs          общие заметки: ключи, журнал, снимки, приглашения
  realtime.rs        канал реального времени
  clip.rs            буфер обмена Windows
  expander.rs        сокращения
server/              сервер активации
```
